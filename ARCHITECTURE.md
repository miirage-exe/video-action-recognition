# Architecture & Workflow

## Two independent workflows

```
┌─────────────────────────────┐     ┌─────────────────────────────┐
│        Google Colab         │     │        Docker (GPU)         │
│                             │     │                             │
│  ActionRecognition_GPU.ipynb│     │  1. make train.py           │
│  ↓ open & run interactively │     │  2. docker compose build    │
│  ↓ data on Google Drive     │     │  3. docker compose up       │
│  ↓ outputs to Google Drive  │     │  ↓ data mounted from ./data │
│                             │     │  ↓ outputs saved to ./outputs│
└─────────────────────────────┘     └─────────────────────────────┘
          ↑                                       ↑
          └──────── single source of truth ───────┘
                  ActionRecognition_GPU.ipynb
```

The **notebook is the single source of truth**. `train.py` is generated from it and never edited by hand.

---

## How paths work in both environments

The notebook reads paths from environment variables with Colab defaults:

```python
DATA_DIR  = Path(os.environ.get("DATA_DIR",  "/content/drive/MyDrive/datasets/UCF-101"))
SPLIT_DIR = Path(os.environ.get("SPLIT_DIR", "/content/ucfTrainTestlist"))
OUT_DIR   = Path(os.environ.get("OUT_DIR",   "/content/drive/MyDrive/datasets"))
```

| Variable   | Colab (default)                          | Docker                            |
|------------|------------------------------------------|-----------------------------------|
| `DATA_DIR` | `/content/drive/MyDrive/datasets/UCF-101`| `/workspace/data/UCF-101`         |
| `SPLIT_DIR`| `/content/ucfTrainTestlist`              | `/workspace/data/UCF-101-TrainTestlist` |
| `OUT_DIR`  | `/content/drive/MyDrive/datasets`        | `/workspace/outputs`              |

## Repository structure

```
.
├── ActionRecognition_GPU.ipynb   # source of truth — edit this
├── Makefile                      # run `make train.py` to generate the script
├── Dockerfile                    # builds the training image
├── docker-compose.yml            # wires GPU + volume mounts
│
├── data/                         # gitignored — mount your dataset here
│   ├── UCF-101/                  # video files (.avi), one folder per class
│   └── UCF-101-TrainTestlist/    # trainlist01.txt, testlist01.txt, classInd.txt
│
├── outputs/                      # gitignored — written by training runs
│   ├── frame_cnn.pth             # trained Frame-level CNN weights
│   ├── c3d_model.pth             # trained C3D weights
│   ├── *.npy                     # predictions and per-class accuracy arrays
│   └── *.png                     # training curves and confusion matrices
│
├── train.py                      # gitignored — generated by `make train.py`
└── ARCHITECTURE.md               # this file
```

---

## Updating the Docker script after editing the notebook

```bash
make train.py          # re-generates train.py from the notebook
docker compose build   # rebuilds the image with the new script
docker compose up      # runs training
```

`make` uses file timestamps — it skips regeneration if the notebook hasn't changed.
